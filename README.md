# JavaScript Practice Scratchpad

A small JavaScript practice repository with a handful of standalone scripts.

## Technology

- JavaScript
- Node.js for running scripts from a terminal (where applicable)

## Run a script

Install Node.js, clone the repository, and run a selected file from the repository root:

```bash
node main.js
```

The current `main.js` prints a short console message. Review each script before running it; the repository is a scratchpad rather than a packaged application.

## Scope

Use this repository for small experiments. Add a short note beside each new exercise describing what it demonstrates, and keep real credentials and private data out of example files.
